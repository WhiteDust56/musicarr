## 2025-02-12 - Added button loading states and form label linking
**Learning:** Adding `:disabled` to buttons bound to loading states in Vue and associating `<label for>` with `<input id>` are high-impact, low-effort accessibility enhancements. The existing CSS structure supported global button styling updates, allowing easy addition of `:disabled` styles (`opacity: 0.6; cursor: not-allowed;`) and disabling `:hover` on disabled elements (`button:hover:not(:disabled)`).
**Action:** When adding or auditing Vue forms, ensure `ref` variables are used to manage loading states during async tasks (e.g., API requests) to disable submitting buttons. Always explicitly link labels to inputs with `for` and `id` tags. Ensure global styles for buttons elegantly handle disabled states.
